## About

My personal portfolio site — a single-file, cinematic scroll experience presenting my journey as a Cloud & DevOps Engineer: skills, projects, certifications, and contact.

## Features

- 🎬 Scroll-driven cinematic scenes — boot, identity, journey, ecosystem, projects, future, contact
- 📄 Downloadable resume (PDF)
- 🔍 SEO-ready: sitemap.xml, robots.txt, and Open Graph preview image
- 📱 Fully responsive — pure HTML, CSS, and JavaScript, no frameworks

## Tech Stack

| Layer        | Technology                              |
| ------------ | --------------------------------------- |
| Markup       | HTML5                                   |
| Styling      | Custom CSS3 (no frameworks)             |
| Interactivity| Vanilla JavaScript                      |
| Typography   | Inter + Fira Code (Google Fonts)        |
| Hosting      | Vercel (auto-deploys on push to `main`) |

## Project Structure

```

├── Mouli_DevOps_Resume.pdf  # Downloadable resume
├── og-image.png             # Open Graph preview image
├── robots.txt               # Crawler rules
├── sitemap.xml              # SEO sitemap
└── LICENSE                  # MIT License
```

## Run Locally

No build step needed:

```bash
# Option 1 — just open it
open index.html

# Option 2 — serve it locally
npx serve .
```

## Deployment

Pushes to `main` deploy automatically to Vercel.
